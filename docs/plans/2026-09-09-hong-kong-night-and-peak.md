# 香港沙盘：日落、夜间与小尺度山顶建筑

## 范围

仅调整香港 Three.js 沙盘，保留 Cesium 地球、北京和纽约入口、照片与天气卡片及现有相机控制接口。光照只提供「日落」「夜间」，默认日落。日落沿用此前的背景、光源色温、强度、阴影与曝光参数。

夜间使用深蓝环境、两方向的柔和照明、独立窗灯以及低透明度建筑边线。窗灯和城市外轮廓各合并为一个几何批次；窗口分布使用独立固定随机种子，不因切换模式重新生成。地标玻璃外壳与窗灯分离，避免整栋楼发光。地标继续采用三种表面材质，夜间额外绘制窗灯与轮廓。

## 山顶

以凌霄阁的上扬碗状外形为参考，增加窗格、细栏杆、台阶、长凳和开放观景台。建筑整体宽度约 0.79、高度约 0.62 个沙盘单位，接近之前宽度 0.78 的体量。近景通过镜头靠近呈现细节，不靠放大模型。

造型参考建筑师 [Farrells 的 Peak Tower 项目说明](https://farrells.com/project/peak-tower/)。该模型是原山顶定位点上的艺术化演绎，不是实际凌霄阁的测绘模型；原沙盘坐标保持不变。

## 后续照片与足迹接口

`hongKongScene.js` 导出 `PEAK_ANCHORS` 和 `getPeakAnchor(id)`，返回局部沙盘三维位置、用途与稳定 ID：

- `peak-sky-terrace`：观景台照片位置，随建筑高度定位。
- `peak-arrival`：山径入口足迹位置，贴合地形。
- `peak-harbour-view`：面向港湾的照片位置，贴合地形。

相机 bridge 增加 `getAnchor(id)` 与 `focusAnchor(id, { signal, duration })`。后续 Director 可先执行 `focusAnchor`，再将真实照片或个人足迹绑定到返回的位置；当前不创建示例个人记录。未知 ID 返回 null，聚焦未知 ID 会拒绝 Promise。

## 远景延伸

2026-09-10 已将早期手绘远景替换为真实经纬度轮廓：港岛、南丫岛、青衣、大屿山使用完整 OSM 岛形，九龙沿岸与新界连成大陆；远处大陆边界以 Natural Earth 补足。原城区的矩形裁切陆地与边线不再渲染，山体连续向外延伸。详见 [海岸线数据与验证](2026-09-10-hong-kong-geography.md)。
