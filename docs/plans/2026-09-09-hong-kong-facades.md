# 香港标签与地标立面

本次调整只涉及香港城市沙盘。地点按钮的常态、悬停、选中态均使用透明背景，无卡片边框或阴影，保留文字、细引线、键盘焦点提示和点击飞行。

IFC、ICC 的四面玻璃幕墙使用独立窗片、竖向窗框、层间分缝和顶部构件。中银大厦的窗片跟随斜屋顶收束，交叉支撑覆盖四面；会展中心补充玻璃分格和曲面屋顶接缝。每座详细模型按石材、玻璃、金属合为最多 3 个几何批次。

香港大学以本部大楼为艺术化原型，补充红砖墙、凹进窗格、开洞拱廊、石柱、中央钟楼、四角小塔与四个院落。原型参考：[香港古物古迹办事处：港大历史建筑](https://www.amo.gov.hk/en/heritage-trails/hku-heritage-sights-and-sites/hku-heritage/index.html)。模型为配合沙盘而放大、简化的程序几何，不是测绘复原；建筑与海岸轮廓仍使用原有 OSM 数据。

香港大学被加入原有地标目录和 `focusLandmark("hku", options)` 镜头接口。相机支持每个地标自己的观察角度与观察高度，用近景查看立面。地球、其他城市与现有 AI action plan 不变。

验证命令：`node --test tests/hongKongFacades.test.js`、`npm run build`。几何测试检查有限坐标、顶点属性、批次数与面数预算，并以射线验证港大拱廊开口、后退玻璃和院落，避免只有贴面而没有空间深度。
