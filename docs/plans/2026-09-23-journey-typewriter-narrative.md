# Journey destination narratives

Keep the existing eight-stop route and attach the supplied copy to each stop.
The first Beijing stop contains two chapters: Beijing and Beijing Institute of
Technology. The remaining stops each contain one chapter.

After the camera and any Hong Kong scene transition arrive, the narrative types
character by character in a narrow, scrollable column. Sentence punctuation and
paragraph boundaries add short pauses. The text uses the existing restrained
serif system, a transparent edge gradient, and no card frame. On desktop, memory
media stays on the opposite side of the viewport.

Automatic travel awaits the narrative promise, including a short hold after the
last character, before moving to the next stop. Manual navigation aborts the
current narrative. Taking camera control or opening a photo pauses automatic
travel while allowing the current narrative to finish.

Narrative data, timing, and visible-character calculation remain separate from
the React component so route coverage and timing can be tested without a browser.
