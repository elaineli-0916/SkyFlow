# SkyFlow · 仍然抬头

沿用现有 Cesium 地球与 Three.js 香港沙盘，新增默认地球叙事层，不替换已有城市和天气能力。

开场只以留白、地球与用户给出的三行文字建立主题。八次抵达按「北京 → 上海 → 纽约 → 马里兰 → 北京 → 香港 → 上海 → 北京」排列；每次抵达是镜头状态和短句，不做履历时间轴。结尾拉远重新看到轨迹与地球，展示用户给出的科学、艺术、技术三行收束文字。

保留两种浏览节奏：手动上一站 / 下一站，以及可暂停的连续旅程。连续旅程在飞行完成后停留；用户拖拽、查看照片或选择城市即暂停，避免镜头争抢。减少动态效果偏好使用即时定位。

真实照片先读取 EXIF（包含经纬度方向）；遇到扩展名伪装成 JPG 的 HEIF 或 QuickTime 视频时，再用本机 `exiftool` 回读同一份原始元数据。用户补全的时间、时区、GPS 与日期精度作为最高优先级写入数据；只有仍缺失时才按文件名或已有照片坐标定位。拍摄年份不等同于迁徙年份；迁徙年份待用户补充。没有上海照片时保留城市光点与短句，不借用别处照片。地球上照片以小光点呈现，悬停、键盘聚焦或触摸点击展开浮动记忆；图片仅展开后加载，离开 / Escape 可关闭。同城照片可切换浏览。原文件保留，公开页面资源不额外上传。

音乐使用用户提供的本地《落叶归根》；由于原文件名含 `#`，准备脚本会复制一个 ASCII 别名 `public/audio/journey-luoye-guigen.mp3`，避免浏览器把文件名中的片段符号当成 URL 锚点。默认关闭，主动点击播放，离开旅程暂停。不展示或补写歌词。

香港移除左侧八景点列表，地图标签继续可点；天气与照片默认折叠。保留默认拖拽平移、Shift / 右键旋转及平移模式开关。

验证：已通过照片坐标与路径顺序、重复城市节点、音乐 URL 与文件存在、相机取消 / 顺序执行、香港地图交互、响应式布局、单元测试及生产构建检查。桌面拖拽平移 / 旋转与小屏布局已在浏览器中检查；原生触摸注入未作为交付依赖。迁徙年份仍留空，等待用户提供，不把照片年份推断成迁徙年份。
